## Portfolio Reflection

### How can I ensure that my code, program, or software is functional and secure?

I think one of the most important ways to make sure software is functional is by testing it against the requirements. Just because a program runs doesn't necessarily mean everything works correctly. For the contact service project, unit testing helps make sure the different methods work as expected and that invalid information is handled properly. Security is also important, which means validating user input and making sure sensitive information is protected. Testing different situations can help catch problems early before they become bigger issues.

### How do I interpret user needs and incorporate them into a program?

I think understanding what the user needs is an important part of developing software. Before writing code, I try to break down the requirements and figure out exactly what the program is supposed to do. From there, I can turn those requirements into individual functions and tests. The contact service project is a good example of this because each requirement needs to be considered when creating and managing contact information. If the requirements aren't understood correctly from the beginning, it can lead to problems later in development.

### How do I approach designing software?

When designing software, I try to start with the basic requirements and break the project into smaller parts. I think this makes it easier to focus on one thing at a time instead of trying to build everything at once. I also try to keep the code organized so it is easier to test, troubleshoot, and make changes later. Working on the contact service project helped me see why it is important to consider testing during development instead of waiting until everything is finished. I think having a plan and testing throughout the process can save a lot of time and prevent unnecessary problems.
